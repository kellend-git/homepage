  • Postman Bootstrap

    Postman Bootstrap

    A regression baseline for agentic migrations

    Led architecture, implementation, evaluation, and delivery from an empty repository to a published PyPI CLI, with workshop fixtures, a browser UI, and a recorded partner demo.

    Implementation and validation

    Behavior preservation
    Recorded legacy API behavior as a replayable contract, then checked for silent surface drift after AWS Transform migrations.
    Validation
    A real transformation run produced two green checks with byte-identical output before and after transformation. In the Northwind fixture and tested setup, the gate detected 15 of 15 planted mutations; a collection authored through the standard Postman CLI path detected 4 of 15.
    Delivery architecture
    Moved execution to a client-side transformation skill when an AWS registration allowlist blocked the original path, removing the dependency from delivery.
    Partner enablement
    Prepared distribution documentation and partner messaging, then shifted effort to SI/GSI enablement while holding new feature development pending customer demand.

    The 15-of-15 result applies to the Northwind fixture and tested setup, not a general detection rate. Commercial adoption was not established by quarter end.

  • Prospect Pipeline

    Prospect Pipeline

    Finding failures that never throw

    Built an eleven-domain LLM prospect-scoring pipeline exposed to Field Engineering through an MCP server, producing account leaderboards and sales briefs.

    Implementation and validation

    Output validation
    Inspected score distributions and identified four silent defects: ratcheting false positives, fabricated weighting values, a fixture mismatch producing zero scores, and negative-polarity signals counted as positive coverage.
    Correction
    Treated affected published results as invalid, reran the analysis, and republished corrected account rankings.

    Outcome scope: scoring reliability improved. Whether high-scoring accounts convert remains unproven.
